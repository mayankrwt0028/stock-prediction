# StockWise India 📈

A stock market analysis and prediction application focused on Indian stocks.

### Features
- Historical stock price charts
- 5-Day Simple Moving Average (SMA) prediction
- Actual vs Predicted price comparison
- MAE and Directional Accuracy metrics

### Tech Stack
- React.js, Vite, Recharts
- Node.js, Express.js
- TejHQ API for stock market data

### Run Locally

**Backend**
```bash
cd backend
npm install
npm start
```

**Frontend**
```bash
cd frontend
npm install
npm run dev
```
